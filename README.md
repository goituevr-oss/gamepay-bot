# 🎮 GamePay — Telegram Mini App для покупки игровой валюты

Современное, стильное и отзывчивое мини-приложение (Telegram Mini App) для продажи игровой валюты популярных игр (PUBG Mobile, Genshin Impact, Mobile Legends, Roblox, Brawl Stars) с футуристичным геймерским дизайном, интерактивными элементами и интеграцией с Telegram WebApp SDK.

---

## ✨ Особенности проекта

*   **👾 Геймерский UI/UX:** Темная тема с неоновыми свечениями (циановый, фиолетовый, золотой), эффектами стекломорфизма (glassmorphism), плавными анимациями и интерактивными карточками.
*   **📱 Адаптивность:** Полностью оптимизирован под мобильные экраны внутри Telegram Webview (предотвращен зум, убраны лишние скроллы).
*   **⚙️ Интеграция с Telegram WebApp SDK:**
    *   Автоматическое получение имени и аватара пользователя Telegram.
    *   Использование тактильной отдачи (Haptic Feedback) при кликах на кнопки, переключении табов и успешной оплате.
    *   Автоматическое расширение приложения на весь экран.
*   **🛒 Удобный процесс покупки:**
    *   **Шаг 1:** Выбор игры (с красивыми превью карточками).
    *   **Шаг 2:** Ввод ID игрока и выбор сервера (динамически меняется под требования конкретной игры).
    *   **Шаг 3:** Выбор готового пакета валюты со скидками или **ввод своей суммы** с помощью интерактивного слайдера.
    *   **Шаг 4:** Переход на кассу с выбором способа оплаты (СБП, Карты РФ, Telegram Stars, Криптовалюта).
*   **📜 Дополнительные экраны:** Встроенная история покупок и страница поддержки (FAQ) прямо внутри приложения.

---

## 📂 Структура проекта

*   `index.html` — Главный файл разметки приложения со всеми экранами, модальными окнами и подключенными библиотеками (Tailwind CSS, Lucide Icons, Telegram WebApp SDK).
*   `styles.css` — Кастомные стили для неонового свечения, анимаций, кастомизации ползунка (слайдера) и адаптации под Telegram.
*   `app.js` — Логика приложения: база данных игр, расчет цен со скидками, валидация полей, переключение шагов, обработка кликов и вызов Telegram Haptic Feedback.

## 🚀 Как запустить локально

Поскольку проект является статическим (HTML + CSS + JS), его можно запустить без сложной настройки:

1.  Просто откройте файл `index.html` в любом браузере.
2.  Для полноценного тестирования функций Telegram WebApp рекомендуется запустить локальный сервер. Например, с помощью расширения **Live Server** в VS Code или через консоль:
    ```bash
    # Если установлен Python
    python -m http.server 8000
    # Или через Node.js
    npx serve .
    ```

## 🌐 Как опубликовать на GitHub Pages (Бесплатно)

Для того чтобы подключить сайт к Telegram Боту, он должен быть опубликован в интернете по протоколу `https://`. GitHub Pages — идеальный и бесплатный способ для этого.

1.  Создайте новый публичный репозиторий на вашем GitHub.
2.  Инициализируйте git в папке проекта и отправьте файлы в репозиторий:
    ```bash
    git init
    git add .
    git commit -m "Initial commit: Telegram Mini App GamePay"
    git branch -M main
    git remote add origin https://github.com/ВАШ_НИКНЕЙМ/ИМЯ_РЕПОЗИТОРИЯ.git
    git push -u origin main
    ```
3.  Перейдите в настройки репозитория на GitHub (**Settings** -> **Pages**).
4.  В разделе **Build and deployment** выберите источник **Deploy from a branch**.
5.  Выберите ветку `main` (или `master`) и папку `/ (root)`, затем нажмите **Save**.
6.  Через 1-2 минуты GitHub предоставит вам ссылку вида `https://ВАШ_НИКНЕЙМ.github.io/ИМЯ_РЕПОЗИТОРИЯ/`. Скопируйте её.

Замените значение `WEBAPP_URL` на реальную ссылку вашего опубликованного сайта на GitHub Pages.

### Шаг 2. Установка зависимостей и запуск сервера
Убедитесь, что у вас установлен [Node.js](https://nodejs.org/). Запустите команды в терминале проекта:
```bash
# Установка библиотек
npm install

# Запуск бота и веб-сервера
npm start
```

### Шаг 3. Регистрация Mini App через BotFather
1. Откройте Telegram и перейдите к [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newapp`.
3. Выберите вашего бота `8652822512` (или введите его юзернейм).
4. Введите название для приложения (например, `GamePay Store`).
5. Введите краткое описание.
6. Загрузите квадратную картинку-иконку.
7. Когда BotFather спросит ссылку на WebApp (`Please send Web App URL`), отправьте ему вашу ссылку от GitHub Pages (например, `https://ВАШ_НИКНЕЙМ.github.io/ИМЯ_РЕПОЗИТОРИЯ/`).
8. Укажите короткое имя для ссылки (например, `shop`).
9. Готово! Бот выдаст вам ссылку вида `t.me/ИМЯ_ВАШЕГО_БОТА/shop`.


### Варианты интеграции реальной кассы:

#### Вариант 1: Через Telegram Stars (Внутренняя валюта Telegram)
Если вы хотите принимать платежи прямо внутри Telegram через Telegram Stars:
1.  На вашем бэкенде (Node.js, Python и т.д.) создайте эндпоинт для генерации инвойса с помощью метода [createInvoiceLink](https://core.telegram.org/bots/api#createinvoicelink).
2.  В `app.js` при клике на «Оплатить» сделайте `fetch` запрос к вашему бэкенду, чтобы получить ссылку на инвойс (`invoice_link`).
3.  Откройте инвойс прямо в Mini App с помощью метода SDK:
    ```javascript
    tg.openInvoice(invoice_link, function(status) {
        if (status === 'paid') {
            // Оплата прошла успешно! Начисляем валюту
            showSuccessModal();
        } else if (status === 'cancelled') {
            // Пользователь закрыл окно оплаты
        } else {
            // Ошибка оплаты
        }
    });
    ```

#### Вариант 2: Подключение платежного шлюза (ЮKassa, СБП, Payok, CryptoPay)
1.  При клике на «Оплатить» отправляйте POST-запрос на ваш сервер с деталями заказа (ID игрока, игра, сумма, выбранный метод оплаты).
2.  Ваш сервер делает запрос к API платежной системы (например, ЮKassa) для создания платежа и получает ссылку на оплату (`confirmation_url`).
3.  Сервер возвращает эту ссылку в Mini App.
4.  В Mini App вы перенаправляете пользователя по этой ссылке или открываете её во встроенном браузере Telegram:
    ```javascript
    tg.openLink(confirmation_url);
    ```
5.  После успешной оплаты платежная система пришлет Webhook на ваш сервер, и ваш скрипт автоматически начислит игровую валюту на ID игрока через API игры или партнерского поставщика.
